para fazer isso primeiro precisa ter um div com classe "topbar", e depois colocar o código JS.
ATENÇÃO no CSS, voce precisa ter uma classe chamada de ".topbar.scrolled", para funcionar o JS

HTML 

<div class="topbar">
    <h1>Santa Menefreda</h1>
    <div class="topbar-links">
        <a href="">Recife</a>
        <a href="">Jaboatão dos Guararapes</a>
        <a href="">Sobre</a>
    </div>
</div>
Título descrição 

<script>
    window.addEventListener("scroll", () => {
    const header = document.querySelector(".topbar");
    if (window.scrollY > 0) {
      header.classList.add("scrolled");
    } else {
      header.classList.remove("scrolled");
    }
    });
</script>
